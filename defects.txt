4. Неверное описание команды CD, CD не отображает файлы и папки, а изменяет текущий каталог.

6. Опечатка в Вернуся на главную

Файл mac.html.
1. mkdir - расфшифровывается  должно расшифровывается
2. Ошибка в описании команды mv, mv не означает "Make directory" (создать папку), а используется для перемещения и переименования файлов и папок.
3. Ошибка в описании команды mkdir, mkdir не означает "Move", а означает "Make Directory" (создать папку).
4. как"Move"  нет пробела, должно:  как "Move"
5. удалить файл/ стоит "/" место точки

Файл git.html
1. mv - расфшифровывается должно расшифровывается
2. как"Move"  нет пробела, должно:  как "Move"
3. Лишний пробел  "202 4", а должно быть "2024"
4. удалить файл/ стоит "/" вместо точки
5. Вернуся на главную должно быть Вернуться на главную
6. Данные команды являются стандартными командами Unix/Linux. должны быть команды например: 
git branch                 # показать список веток
git stash     # временно сохранить незакоммиченные изменения и убрать их из рабочей директории
git remote -v              # показать список удалённых репозиториев, связанных с локальным
git branch -r              # показать удаленные ветки
git init                      # создаём репозиторий в этой директории
git add readme.md             # добавляем файл в индекс
git commit -m "Старт"         # создаем коммит
git rm text.txt    # удалить отслеживаемый неизменённый файл и проиндексировать это изменение
